# Travel & Visa Rules — Working Abroad on a World Tour

Legal reality-check for the adventure-retirement plan (`../savings/adventure-retirement-plan.md`). Key correction to a common misconception.

---

## 1. The Misconception

> "If I'm not salaried, I don't need a work visa."

**Wrong.** Trading services for free accommodation (e.g., teaching yoga at a hostel in exchange for your stay) is **still considered work** by immigration authorities.

- Tourist visa / visa-free entry ≠ authorization to work.
- Any exchange of services for value (cash **or** in-kind like free lodging) is work.
- Working without authorization can carry **serious consequences** (deportation, entry bans).

## 2. The Japanese Passport (Strong, but Not a Free Pass)

- Japanese passport is one of the strongest in the world — visa-free / visa-on-arrival access to the vast majority of countries.
- **The catch:** those visa-free entries are almost universally **for tourism / short visits**.
- Any work — including day jobs like yoga teaching or translating — still requires the appropriate **work visa/permit** for each country.

## 3. Working Rules That Actually Apply

| Activity | Needs work visa? |
| :--- | :--- |
| Sightseeing / tourism | No (covered by visa-free entry) |
| Volunteering with no value exchange (some countries) | Grey area — check each country |
| Teaching yoga for free stay (barter) | **Yes** |
| Any paid work, even casual/under-the-table | **Yes** |
| Remote work for a foreign employer | Depends on country rules (digital nomad visas) |

## 4. Practical Implications for the Plan

- **Don't rely on barter work** to cut costs unless you've verified that country's rules (and the enforcement reality).
- **Day-job income (yoga/translator)** can cut the travel budget in half, but plan it as **legal** work per country — or treat it as a bonus, not the foundation of the budget.
- **Remote/online income by ~40 is questionable** anyway (AI pressure) — so the nest egg (`$240K–320K`) should be the **primary** funding source, with day jobs as optional extras.

## 5. Action Items

- Before the tour, research work rules for each target region (SEA, South America, Europe, US) individually.
- Consider **digital nomad visas** for countries that offer them if remote income becomes feasible.
- Keep the budget plan self-sufficient (no dependence on illegal/unclear work).
