# Slack Keyboard Shortcuts — Mac & Windows/Linux

> Source: Slack Help Center. Two-column format below: **Mac** | **Windows/Linux**.
> Notes: `*` shortcut may vary by keyboard. `**` desktop app only. `†` press F6 to focus first.

## Basics

| Action | Mac | Windows/Linux |
| --- | --- | --- |
| Compose a new message | `⌘ N` | `⌘ Shift K` |
| Unsend a message | `⌘ Z` | `⌘ Z` |
| Set your status | `⌘ Shift Y` | `⌘ Shift Y` |
| Open your preferences** | `⌘ ,` | `Ctrl ,` |
| Resize the left sidebar† | `⌘ [` / `⌘ ]` (click) | `Ctrl [` / `Ctrl ]` (click) |
| Hide the right sidebar | `⌘ .` | `Ctrl .` |
| Create a new canvas | `⌘ Shift N` | `Ctrl Shift N` |
| Upload a file** | `⌘ O` | `Ctrl O` |
| View all downloaded files | `⌘ Shift J` | `Ctrl Shift J` |
| Create a new snippet | `⌘ Shift Enter` | `Ctrl Shift Enter` |
| Add an emoji reaction to a message* | `⌘ Shift \` | `Ctrl Shift \` |
| Start a search | `⌘ G` | `Ctrl G` |
| Search in the current conversation | `⌘ F` | `Ctrl F` |
| Start, join, leave, or end a huddle | `⌘ Shift H` | `Ctrl Shift H` |
| Toggle mute on a huddle | `⌘ Shift Space` | `Ctrl Shift Space` |
| Open Help | `F1` | `F1` |
| Toggle full screen view | `⌘ Ctrl F` | `Ctrl Shift F` |
| Close window | `⌘ W` | `Ctrl W` |
| Reopen last closed window | `⌘ Shift W` | `Ctrl Shift W` |
| Open the People view | `⌘ Shift E` | `Ctrl Shift E` |
| Quit Slack** | `⌘ Q` | `Ctrl Q` |

| Jump to next channel/DM in sidebar | `Option ↓` | `Alt ↓` |

| Go forward in history | `⌘ ]` | `Ctrl ]` |

| Browse DMs | `⌘ Shift K` | `Ctrl Shift K` |
| Open the Activity view** | `⌘ Shift M` | `Ctrl Shift M` |
| Open the More View | `Ctrl 0` | `Ctrl 0` |

| Move focus to the next section | `F6` | `F6` |

## Switch workspaces

| Action | Mac | Windows/Linux |
| --- | --- | --- |
| Expand/collapse workspace switcher | `⌘ Shift S` | `Ctrl Shift S` |
| Switch to previous workspace | `Ctrl Shift Tab` | `Ctrl Shift Tab` |
| Switch to next workspace | `Ctrl Tab` | `Ctrl Tab` |
| Switch to a specific workspace | `⌘ [number]` | `Ctrl [number]` |

> Hover over a workspace icon in the left sidebar to see its assigned number.

## Switch tabs

| Action | Shortcut |
| --- | --- |
| Switch to the previous tab | `Ctrl Page up` |
| Switch to the next tab | `Ctrl Page down` |
| Switch to a specific tab | `Ctrl [number]` |

> Hold `Ctrl` to see a tab's assigned number in the navigation bar.

## Take actions on messages (one-key, when message focused)

| Action | Shortcut |
| --- | --- |
| Edit a message you sent | `E` |
| Delete a message you sent | `Delete` |
| Open or reply to a thread | `T` |
| Forward a message | `F` |
| Pin or unpin a message | `P` |
| Save a message (or remove from Later) | `A` |
| Mark all messages above the focused one as unread | `U` |
| Create a reminder about a message | `M` |
| Add an emoji reaction to a message | `R` |

> Tip: By default, `↑` in the message field edits your last message. Adjustable in preferences.

| --- | --- |

| Quote selected text | `⌘ Shift 9` / `Ctrl Shift 9` |
| Code selected text | `⌘ Shift C` / `Ctrl Shift C` |
